# SaaS Executive Dashboard

An interactive dashboard concept for exploring SaaS business performance through an executive-friendly interface. This repository describes a dashboard built with HTML, JavaScript, and Tailwind CSS.

## Purpose

An executive dashboard should help decision-makers understand performance quickly, notice important changes, and ask the next useful question—not simply display a large number of charts.

## Metrics to Consider

Depending on the data and calculations implemented in the project, relevant SaaS metrics may include:

- Monthly recurring revenue (MRR) and annual recurring revenue (ARR)
- Customer churn and revenue churn
- Customer acquisition cost (CAC)
- Customer lifetime value (LTV)
- Net revenue retention (NRR)
- Trial-to-paid conversion
- Expansion and contraction revenue

These are suggested metric categories, not a claim that every metric is implemented in the current dashboard. Document each metric's formula, time period, and data source before using it.

## What Makes a Useful Executive Dashboard?

- Clear metric definitions and time periods
- A small set of decision-relevant KPIs
- Consistent number formats and units
- Visual comparisons that reveal trends, not just totals
- Visible distinctions between real, sample, and simulated data
- Responsive layouts and readable contrast
- Honest notes about missing data and limitations
